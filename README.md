# Cu IDE

<img width="343" height="291" alt="Cu" src="https://github.com/user-attachments/assets/d3896349-9b6d-4ced-a4e1-7381cc39e124" />


Cu is a lightweight, minimalist Integrated Development Environment (IDE) designed specifically for writing and compiling C# code using the .NET SDK. 

It is a fork of the Mu Editor, retaining its simple, distraction-free interface while replacing the Python backend with a streamlined pipeline for C# development.

## Features

* **Minimalist Interface:** A clean editor layout focused entirely on writing code without overwhelming sidebars or complex menu configurations.
* **Integrated .NET Pipeline:** Utilizes Python's subprocess automation to link directly to the .NET CLI for compiling and running scripts.
* **C# Syntax Highlighting:** Configured via custom text component configurations to parse C# keywords, operators, and types accurately.

## Background & Project Origins

This project was created as a functional alternative to heavy, resource-intensive C# editors, built on the structural foundation of the sunsetted Mu Editor. While the backend mechanics have been adapted for compiled code, the overall interface design remains dedicated to the user experience established by the original Mu development team.
